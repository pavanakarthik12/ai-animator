ROOT CAUSE FIXED:
  Pixel sampling (25 or 100 points) was missing small characters on large canvas.
  
  Example: Character 150x300 on canvas 800x600
  Sampling only 100 points might hit 0-2 pixels → FALSE NEGATIVE

SOLUTION IMPLEMENTED:
  Use Krita's actual content bounds API (node.bounds())
  - Finds content regardless of size or position
  - No sampling, no thresholds, no guessing
  - Direct API from Krita itself

===============================================================================
                    WHY THIS WORKS
===============================================================================

Old Method (Pixel Sampling):
  - Sample 100 fixed points across canvas
  - Count how many are non-white
  - Problem: Small character between sample points → missed

New Method (Content Bounds):
  - Ask Krita: "Where is the actual drawn content?"
  - Krita returns exact bounding rectangle
  - If bounds exist → content exists
  - Works for ANY size, ANY position

Example:
  Canvas: 2000x2000
  Character: 150x300 at position (1500, 800)
  
  Old method: Might sample 0 pixels from character → FALSE
  New method: bounds() returns 150x300 at (1500,800) → TRUE
