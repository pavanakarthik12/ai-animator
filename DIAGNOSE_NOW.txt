                    STEP 2: TEST ONE SIMPLE LINE

    python test_one_line.py

It will:

  2. Check detection returns FALSE

If this test FAILS, we know detection itself is broken.
If this test PASSES, the problem is with character location/layer/frame.

===============================================================================
                    POSSIBLE OUTCOMES
===============================================================================

Scenario A: diagnose_krita_state.py shows 0/100 pixels
            BUT character IS visible in Krita
    → Character is on wrong layer/frame
    → Detection is checking wrong location

Scenario B: diagnose_krita_state.py shows >0 pixels
            AND character_detected = TRUE
    → Detection is working correctly
    → Animation should proceed

Scenario C: test_one_line.py draws line
            Line is visible in Krita
            BUT detection returns FALSE
    → Detection logic has a bug

Scenario D: test_one_line.py draws line
            Line is NOT visible in Krita
    → Drawing API has a problem (separate issue)

===============================================================================
                    DETECTION LOGIC CHANGES
===============================================================================

Old logic:
  - Sampled 25 pixels (5x5 grid)
  - Required 5+ non-blank pixels (20% threshold)

New logic:
  - Samples 100 pixels (10x10 grid)
  - Requires >0 non-blank pixels (ANY content)
  - More aggressive sampling
  - Lower threshold
  - More detailed logging

Pixel detection:
  - White (#ffffff) = blank
  - Transparent (#00000000) = blank
  - Any other color = non-blank
  - Logs first 3 non-blank pixels found
